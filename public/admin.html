Подключение Google Таблицы (5 минут)

  1. Создайте Google Таблицу, скопируйте её ID из ссылки.
  2. Откройте Расширения → Apps Script, вставьте код из файла google-apps-script/Code.gs в репозитории.
  3. Заполните SHEET_ID, API_SECRET, (необязательно BOT_TOKEN, ADMIN_CHAT_ID).
  4. Развернуть → Новое развертывание → Веб-приложение, доступ «Все».
  5. URL вставьте в Render → Environment → APPS_SCRIPT_URL, секрет — в API_SECRET, перезапустите сервис.

Telegram-бот (кнопка с сайтом)

  1. Напишите @BotFather → /newbot, заберите токен → в BOT_TOKEN.
  2. Узнайте свой chat id через @userinfobot → в ADMIN_CHAT_ID (сюда придут заявки).
  3. В BotFather: /setmenubutton → выберите бота → вставьте адрес сайта на Render. Готово: в боте появится кнопка «Открыть запись».

Подробно — в README.md репозитория.
