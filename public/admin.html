Где лежат данные

Листы таблицы: Slots (слоты), Bookings (заявки), Settings (настройки сайта), Users (пользователи бота), Messages (переписка/рассылки), Students (карточки учеников), Notes (домашки/сообщения в кабинет), Tests + TestAssign (тесты и попытки учеников — отдельные листы, основную БД не засоряют), TopicCatalog (свой список пройденных тем для чекбоксов: колонки subject, grade, topics через запятую; если лист пуст — используется встроенный список 4–9 классов). 📝 Тесты: как готовить

  1. Вкладка Тесты → «Создать тест». В форме есть блок 🤖 Промпт для ИИ: заполните предмет/класс/тему/количество вопросов → «Скопировать промпт» → вставьте в ChatGPT/Claude/Gemini. ИИ ответит текстом, который сайт сам разберёт (строки «Ответ: б» и «Пояснение: …» подхватываются автоматически).
  2. Или вставьте готовый тест из учебника/сайта → «Разобрать». Понимаются форматы: «1. Вопрос / а) вариант / Ответ: б», ключ в конце («Ответы: 1-б, 2-а»), вопросы с открытым ответом («Ответ: 3,14») и JSON.
  3. Проверьте предпросмотр (правильные варианты отмечены зелёным) и сохраните. Настройки теста: показ ученику правильности после каждого ответа, итоговый балл, запрет копирования текста и количество попыток (по умолчанию 1 — можно, например, 3).
  4. Сохранённый тест можно править в любой момент: «✏️ Редактировать» — название, вопросы (JSON), настройки. Ученик, который ещё не начал, увидит новую версию.
  5. «Отправить ученику» — создаст персональную ссылку /test.html?t=…: тест появится в кабинете и/или придёт от бота в Telegram. Правильные ответы не видны до ответа на каждый вопрос.
  6. Результаты — кнопка «Результаты» у теста: кто начал/закончил, сколько попыток, балл и ответ на каждый вопрос. Когда ученик завершает тест, вам приходит уведомление в Telegram.

✏️ Как поправить ФИО ученика

Вкладка Ученики → карточка → поле «ФИО ученика» → «Сохранить». Новое имя автоматически подставится в заявки и расписание — в таблицу лазить не нужно.

⚠️ Ошибка «You can't set the number format of cells in a typed column»

В таблице у колонки date или time включён «тип колонки» (Sheets → таблица/типизированная колонка). Код v3 это обходит автоматически — просто обновите Code.gs и сделайте Новую версию развертывания. Если хотите убрать причину: выделите колонки date/time → Формат → Число → Обычный текст, либо преобразуйте «таблицу» обратно в диапазон.

⚠️ Слоты есть в таблице, но их нет на сайте

  1. Убедитесь, что в Apps Script вставлен актуальный Code.gs из репозитория (вверху написано «v3»).
  2. После изменения кода: Развернуть → Управление развертываниями → ✏️ → Новая версия. Без этого сайт видит старый код!
  3. Проверьте SHEET_ID и API_SECRET (= как в Render).
  4. Диагностика: откройте /api/slots?date=ГГГГ-ММ-ДД — должен прийти JSON. Если forbidden — не совпадает API_SECRET.

Telegram-бот: уведомления, рассылки, напоминания

  1. @BotFather → /newbot → токен в Render → BOT_TOKEN. Свой chat id (@userinfobot) → ADMIN_CHAT_ID. Адрес сайта → PUBLIC_URL.
  2. Вкладка Telegram → «Подключить вебхук» (один раз). После этого бот отвечает на /start, просит поделиться номером, а все сообщения учеников попадают в админку.
  3. Чтобы напоминания приходили ученику, он должен нажать /start в боте и поделиться номером — номер связывается с его записями.
  4. Для самих напоминаний: в Code.gs заполните BOT_TOKEN и ADMIN_CHAT_ID, в редакторе выберите функцию createReminderTrigger → ▶️ → разрешите доступ. За сколько минут напоминать — в Настройках.
  5. @BotFather → /setmenubutton → адрес https://ваш-сайт/telegram.html — кнопка «приложение» в боте.

Перенос и отмена занятий

Ученик может только записаться и перенести занятие (не позже чем за N часов — задаётся в Настройках). Отменить может только преподаватель: вкладка Заявки → «Отменить» (слот освобождается, ученику уходит сообщение в Telegram, если он привязан).

Личный кабинет ученика

Страница /cabinet.html, вход по номеру телефона (тестовый режим, без пароля; сессия хранится — при обновлении страницы вход не нужен). Вкладки: Главная (ближайшее занятие, статистика, «Перенести занятие»), Расписание (календарь всех занятий — прошедших и будущих), Тесты, Сообщения (домашки/ссылки), Темы. Разделы подгружаются при открытии. Отключить кабинет можно в Настройках.

Если что-то сломалось

  1. Сайт не открывается / долго грузится — free-тариф Render «засыпает», первый визит 30–60 сек. Логи: Render → Logs.
  2. Ошибка при записи — проверьте, что Apps Script развернут новой версией и доступ «Все».
  3. Не приходят уведомления — проверьте BOT_TOKEN/ADMIN_CHAT_ID (в Render и в Code.gs) и что вы нажали /start в боте.
  4. Сбросить настройки сайта — Настройки → «Сбросить», либо очистить лист Settings.
