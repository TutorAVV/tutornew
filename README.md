# 🎓 Сайт репетитора — запись на ЕГЭ/ОГЭ + Telegram WebApp + админка

Современный сайт для репетитора (подготовка к ЕГЭ/ОГЭ): ученик выбирает предмет, дату и время **отдельными кнопками-слотами** (как в Telegram-приложении), оставляет имя и телефон. Заявки падают в **Google Таблицу**, админ управляет слотами в **админ-панели в том же стиле**. В Telegram бот открывает **ту же страницу** как мобильное WebApp.

Всё бесплатно: **Render.com (free)** + **Google Sheets + Apps Script (free)**.

---

## 1. Что внутри

```
tutornew/
├── server.js                  # сервер для Render: статика + API + прокси к Google Таблице
├── package.json
├── render.yaml                # готовый blueprint для Render
├── public/
│   ├── index.html             # сайт: hero, предметы, запись, цены, отзывы, FAQ
│   ├── styles.css             # общий стиль сайта и админки
│   ├── app.js                 # логика записи + Telegram WebApp
│   ├── admin.html             # админ-панель (заявки / слоты / настройка)
│   └── admin.js
├── google-apps-script/
│   └── Code.gs                # backend на Apps Script (вставить в таблицу)
└── data/                      # демо-хранилище, если таблица ещё не подключена
```

**Страницы:**
- `/` — сайт и запись (на телефоне выглядит как приложение)
- `/admin.html` — админ-панель (пароль из `ADMIN_KEY`)

## 2. Запуск на Render.com (бесплатно, ~10 минут)

**Вариант А — через Blueprint (проще всего):**
1. Залейте этот репозиторий на GitHub.
2. На [render.com](https://render.com) → **New → Blueprint** → выберите репозиторий. `render.yaml` всё настроит сам.
3. После деплоя Render выдаст адрес вида `https://tutor-booking-xxxx.onrender.com` — это и есть сайт. Откройте его, проверьте запись (пока в демо-режиме).
4. Во вкладке **Environment** задайте переменные (см. ниже) → **Save** → сервис перезапустится.

**Вариант Б — вручную:** New → Web Service → ваш репозиторий → Build: `npm install`, Start: `node server.js`, Plan: Free.

**Переменные окружения (Render → Environment):**

| Переменная | Обязательно | Что это |
|---|---|---|
| `ADMIN_KEY` | да (генерируется) | пароль от `/admin.html` |
| `API_SECRET` | да (генерируется) | общий секрет сайта ↔ Apps Script |
| `APPS_SCRIPT_URL` | для прода | URL веб-приложения Apps Script (`.../exec`) |
| `SHEET_URL` | нет | ссылка на Google Таблицу (кнопка в админке) |
| `BOT_TOKEN` | для уведомлений | токен бота от @BotFather |
| `ADMIN_CHAT_ID` | для уведомлений | ваш chat id (узнать: @userinfobot) |
| `TUTOR_NAME` | нет | имя в шапке, по умолчанию «Репетитор» |
| `TUTOR_SUBJECTS` | нет | предметы через запятую |
| `TUTOR_PHONE` | нет | (зарезервировано) |

> ⚠️ На бесплатном тарифе Render сервис «засыпает» без трафика и просыпается ~30–60 сек при первом визите — это нормально. Демо-данные (`data/db.json`) на free-диске живут до перезапуска — поэтому для прода подключайте Google Таблицу (раздел 3).

## 3. Google Таблица + Apps Script (хранилище заявок, бесплатно)

1. Создайте пустую **Google Таблицу**.
2. В ней **Расширения → Apps Script** → удалите содержимое → вставьте код из `google-apps-script/Code.gs` → 💾 Сохранить.
3. Вверху файла заполните:
   - `SHEET_ID` — кусок из ссылки на таблицу (`.../spreadsheets/d/XXX/edit`),
   - `API_SECRET` — тот же секрет, что в Render,
   - (необязательно) `BOT_TOKEN` и `ADMIN_CHAT_ID` — тогда заявки будут приходить вам в Telegram прямо из таблицы.
4. **Развернуть → Новое развертывание** → тип «Веб-приложение» → *Выполнять от имени: Я* → *Доступ: Все* → Развернуть → скопируйте URL `.../exec`.
5. Вставьте URL в Render → `APPS_SCRIPT_URL`, секрет в `API_SECRET` → Save. Готово: сайт пишет в таблицу.

В таблице автоматически появятся листы:
- **Slots** — `date | time | format | subject | status | student | phone`
- **Bookings** — `id | createdAt | date | time | subject | format | name | phone | grade | comment | contact | source | status`

Старую логику на Google Scripts можно переиспользовать — endpoint'ы совместимы по смыслу (`getSlots`, `book`, `getBookings`…); проще взять готовый `Code.gs` целиком.

## 4. Telegram: бот + мобильная версия (бесплатно)

Отдельное приложение писать **не нужно**: бот открывает этот же сайт как WebApp — на телефоне он выглядит как приложение из скриншота (крупные кнопки-слоты, адаптив, тема Telegram подхватывается автоматически).

1. Напишите **@BotFather** → `/newbot` → имя и username → заберите **токен** → в Render `BOT_TOKEN`.
2. Узнайте свой id через **@userinfobot** → в Render `ADMIN_CHAT_ID` (сюда упадут уведомления «🆕 Новая заявка»).
3. В **@BotFather**: `/setmenubutton` → выберите бота → вставьте адрес сайта с Render. У бота появится кнопка — по ней открывается запись.
4. По желанию: `/setdescription`, `/setabouttext`, аватарка. Команды бота не нужны — весь функционал уже в WebApp.

Проверка: откройте бота с телефона → кнопка меню → выбираете слот кнопками → заявка падает в таблицу и вам в личку.

## 5. Админ-панель

Откройте `https://ваш-адрес.onrender.com/admin.html`, введите `ADMIN_KEY`. Вкладки:

- **📋 Заявки** — фильтр по статусу, поиск, подтверждение/отмена (отмена освобождает слот), выгрузка в CSV.
- **🕒 Слоты** — слоты на день отдельными карточками, добавление, удаление, генерация на период (например, пн–пт 15:00–20:00).
- **❓ Настройка** — статус подключения таблицы и краткие инструкции.

Стиль — тот же, что у сайта. Если таблица не подключена — панель работает в демо-режиме.

---

## 6. Локальный запуск

```bash
npm install
ADMIN_KEY=admin123 npm start
# сайт: http://localhost:3000, админка: http://localhost:3000/admin.html
```

Старый хостинг на GitHub Pages тоже возможен для витрины, но запись и админка требуют сервера (Render) или Apps Script напрямую — поэтому рекомендованный путь: всё на Render + таблица.
