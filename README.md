# 📐 Онлайн-уроки (математика и физика) — сайт + Telegram + админка (v3)

Ученик сам выбирает время кнопками-слотами и записывается без звонков, может **перенести** занятие (не позже чем за N часов — настраивается), получает **напоминание** в Telegram. Отменить занятие может **только преподаватель**. Заявки и телефоны — в **Google Таблице** (старая таблица поддерживается как есть). Всё бесплатно: **Render.com** + **Google Sheets + Apps Script**.

**Новое в v3:** настройки сайта прямо из админки (без правки кода), вкладка Telegram (переписка с учениками через бота + массовая рассылка с защитой от случайного нажатия), вкладка Ученики (карточки, статистика, домашки/ссылки), личный кабинет ученика `/cabinet.html` (вход по телефону), расписание сгруппировано по дням, исправлена ошибка «You can't set the number format of cells in a typed column» при массовом добавлении слотов.

**Новое в v3.1:**
- **📝 Тесты**: вставляете готовый тест (из учебника, сайта или сгенерированный ИИ) в админку → «Тесты» → сайт сам разбирает вопросы/варианты/ответы. Каждому ученику — персональная **одноразовая ссылка** `/test.html?t=…` (в кабинет и/или Telegram). Обратная связь после ответа и итоговый балл — на усмотрение преподавателя; правильные ответы ученику не видны до ответа. Результаты — в админке + уведомление в Telegram. Хранится в отдельных листах `Tests`/`TestAssign` (основную БД не трогают).
- Кабинет ученика: сессия запоминается (localStorage) — при обновлении страницы не надо вводить телефон заново; блок «Задания (тесты)»; маска номера при входе.
- Админка: всплывающие уведомления обо всех действиях (тосты) + страница не «прыгает» после изменений; чекбоксы «куда отправить» (кабинет / Telegram) у сообщений ученику; редактирование ФИО ученика обновляет его имя в заявках и расписании автоматически.
- Слоты на сайте — просто время (`17:00`), часовой пояс — одной строкой в шапке («Занятия проходят онлайн по Екатеринбургскому времени (МСК+2)»); фикс подсветки кнопок, тёмной темы шапки, переноса длинных сообщений.

## 1. Деплой на Render.com

1. Репозиторий на GitHub → Render → **New → Blueprint** → выбрать репозиторий.
2. Адрес вида `https://tutor-booking-xxxx.onrender.com` — это сайт.
3. **Environment** → задать переменные → Save:

| Переменная | Значение |
|---|---|
| `ADMIN_KEY` | пароль админки (генерируется) |
| `API_SECRET` | секрет сайт↔Apps Script (генерируется) |
| `APPS_SCRIPT_URL` | URL веб-приложения `.../exec` |
| `SHEET_URL` | ссылка на таблицу (кнопка в админке) |
| `BOT_TOKEN` | токен от @BotFather |
| `ADMIN_CHAT_ID` | ваш chat id (@userinfobot) |
| `PUBLIC_URL` | адрес сайта, например `https://tutor-booking-xxxx.onrender.com` (нужен боту для кнопки «Записаться» и вебхука) |
| `TUTOR_NAME` | `Онлайн-уроки` (значение по умолчанию — дальше меняется в админке → Настройки) |
| `TUTOR_TG` | `aviation09` (без @) |
| `TUTOR_SUBJECTS` | `Математика,Физика` |
| `TZ_LABEL` | `МСК+2` |
| `LESSON_DURATION` | `50` |
| `RESCHEDULE_HOURS` | `12` — за сколько часов до занятия ещё можно перенести (меняется в админке) |

> `TUTOR_NAME`, `TUTOR_SUBJECTS`, `TZ_LABEL`, `LESSON_DURATION`, `RESCHEDULE_HOURS` — только значения **по умолчанию**. Всё это (плюс заголовок вкладки, тексты на главной, классы, время напоминания и т.д.) преподаватель меняет в **админке → ⚙️ Настройки** — сохраняется в лист `Settings` таблицы и применяется сразу, без деплоя.

> На free-тарифе сервис засыпает без трафика, первый визит ~30–60 сек — нормально.

## 2. Таблица + Apps Script (v2)

**Старую таблицу и слоты удалять НЕ нужно** — v2 находит колонки по названиям (`date/time/duration/status/student/email/phone` или русские), понимает даты `ДД.ММ.ГГГГ` и ISO, статусы `open/booked/closed`.

1. В таблице: **Расширения → Apps Script** → заменить код на `google-apps-script/Code.gs`.
2. Заполнить `SHEET_ID`, `API_SECRET` (= как в Render), `BOT_TOKEN`, `ADMIN_CHAT_ID`.
3. **Развернуть → Новое развертывание → Веб-приложение** (Я / Все) → URL в `APPS_SCRIPT_URL`.
4. ⚠️ **После каждого изменения кода**: Управление развертываниями → ✏️ → **Новая версия**. Иначе сайт видит старый код — самая частая причина «слоты не отображаются».

### Если слоты есть в таблице, но их нет на сайте
1. Проверьте, что в Apps Script — код **v2** (вверху комментарий «Tutor booking v2»).
2. Сделайте **Новую версию** развертывания (п. 4 выше).
3. Проверьте `SHEET_ID` и `API_SECRET`.
4. Диагностика в браузере: откройте `https://ваш-сайт/api/slots?date=ГГГГ-ММ-ДД` — должен прийти JSON со слотами. Если `{"ok":false,"error":"forbidden"}` — не совпадает `API_SECRET`.

## 3. Telegram-бот

1. **@BotFather** → `/newbot` → токен в `BOT_TOKEN`.
2. Свой id через **@userinfobot** → в `ADMIN_CHAT_ID` (сюда: новые заявки, отмены, копии напоминаний).
3. **@BotFather** → `/setmenubutton` → адрес сайта. В боте появится кнопка — это и есть «приложение»: та же страница, адаптированная под телефон.
4. Ученик записывается и **перезаписывается сам** («Мои записи» по номеру телефона: отмена → выбор нового времени). Звонки не нужны.

### Вебхук: бот отвечает, собирает номера, пересылает сообщения
1. `BOT_TOKEN`, `ADMIN_CHAT_ID`, `PUBLIC_URL` заполнены в Render.
2. Админка → вкладка **✈️ Telegram** → «Подключить вебхук» (один раз).
3. Теперь `/start` в боте предлагает **поделиться номером** — номер связывается с записями ученика (лист `Users`). Любое сообщение ученика в бот попадает в админку (лист `Messages`) и дублируется вам в Telegram; ответить можно из админки. Там же — **массовая рассылка** всем пользователям бота (нужно ввести слово «РАЗОСЛАТЬ» и подтвердить ещё раз — от случайного нажатия).

### Напоминания
Chat id ученика берётся из записи через бота **или** по номеру телефона из `Users` (если ученик поделился номером). Записи с сайта без Telegram напоминаний не получат.
1. В `Code.gs` заполнены `BOT_TOKEN` и `ADMIN_CHAT_ID`.
2. В редакторе Apps Script выбрать функцию **`createReminderTrigger`** → ▶️ → разрешить. Проверка каждые 15 минут; за сколько минут напоминать — админка → Настройки (`reminderMinutes`, по умолчанию 60).

## 4. Админ-панель (`/admin.html`)

- **🗓 Расписание** — все слоты на 60 дней **включая занятые** (имя, телефон — кликабелен, email, предмет). Действия: закрыть/открыть, **освободить**, **удалить** — о каждом действии приходит всплывающее уведомление, страница остаётся на месте. Кнопка «🧹 Удалить прошедшие» (занятые оставляет как историю), очистка диапазона (закрыть/удалить), выгрузка CSV. В таблицу лазить не нужно.
- **📋 Заявки** — новые/подтверждённые/завершённые/отменённые, поиск, CSV. Отмена освобождает слот.
- **➕ Слоты** — добавить один (дата/время/длительность), генерация на диапазон: окна будни/выходные, длительность, шаг, «не изменять существующие». Генерация пишет строки пачкой — быстро и без ошибки typed column.
- **🎓 Ученики** — карточки создаются сами при первой записи: имя, класс, предмет, статистика (проведено/впереди/отменено), пройденные темы (видит ученик), заметки (не видит). Поле «ФИО ученика» при сохранении обновляет имя и в заявках, и в расписании. Отправка домашки/сообщения/ссылки — с чекбоксами «в кабинет» / «в Telegram» (по умолчанию оба, можно отключить одно).
- **📝 Тесты** — создание из готового текста/JSON, отправка ученику (кабинет + Telegram), результаты по каждому вопросу. Подробно в разделе 4.3.
- **✈️ Telegram** — пользователи бота, переписка, ответ от имени бота, массовая рассылка с двойным подтверждением.
- **⚙️ Настройки** — название, заголовок вкладки, тексты главной, предметы, классы, длительность, часы для переноса, минуты для напоминания, часовой пояс, контакт, вкл/выкл кабинет. Применяется сразу.
- **❓ Помощь** — подсказки «что делать, если сломалось» (typed column, слоты не видны, бот молчит и т.д.).

## 4.1 Личный кабинет ученика (`/cabinet.html`)
Тестовый режим: вход по номеру телефона без пароля (с маской +7). Вход запоминается в браузере — при обновлении страницы номер вводить заново не нужно («Выйти» сбрасывает). Ученик видит ближайшие занятия (с кнопкой переноса), статистику, пройденные темы, сообщения/домашки/ссылки, **задания-тесты** и историю. Отключается в Настройках (`cabinetEnabled = 0`).

## 4.2 Тесты (`/test.html`)
1. Админка → **Тесты** → «＋ Создать тест» → вставьте тест текстом или JSON. Понимаемые форматы:
   - «1. Вопрос / а) вариант / Ответ: б» (варианты: а) б) в), А) B), 1) 2), «-», «•»);
   - ключ в конце: «Ответы: 1-б, 2-а» или «Ключ: 1.Б 2.Г»;
   - открытые вопросы без вариантов: «Ответ: 3,14»;
   - JSON: `{"title":"…","questions":[{"text":"…","options":["…"],"correct":2},{"text":"…","answer":"7"}]}` (номера правильных вариантов — с единицы; можно попросить ИИ выдать такой JSON).
   - Несколько правильных ответов тоже поддерживаются: «Ответ: 1,3» — ученик отмечает галочками все подходящие варианты.
2. Перед сохранением показывается предпросмотр (правильные варианты отмечены ✓), название и два переключателя: «показывать ученику правильность после ответа» и «показывать итоговый балл». Если что-то разобралось не так — правится JSON под спойлером.
3. «📤 Отправить ученику» создаёт **персональную одноразовую ссылку**: тест появляется в кабинете ученика и/или приходит от бота. Пройти можно один раз, ответ на вопрос даётся один раз, правильные ответы до ответа не отправляются на клиент.
4. «📊 Результаты»: кто начал/закончил, балл, ответ на каждый вопрос (✅/❌). Когда ученик завершает тест, преподавателю приходит уведомление в Telegram. Ошибочную отправку можно отменить («✕») — ссылка гаснет, тест скрывается из кабинета.

## 4.3 Листы таблицы
`Slots`, `Bookings` — как раньше (колонка `format` в Bookings не используется, можно удалить). Новые листы создаются автоматически: `Settings` (key/value), `Users` (пользователи бота), `Messages` (переписка и рассылки), `Students` (карточки), `Notes` (сообщения в кабинет), `Tests` + `TestAssign` (тесты и попытки — отдельные листы, основную БД не засоряют).

> Для автопереименования ФИО в Google Таблицах нужен обновлённый `Code.gs` (действие `renameStudent`) — после обновления кода не забудьте сделать **новую версию развертывания**.
